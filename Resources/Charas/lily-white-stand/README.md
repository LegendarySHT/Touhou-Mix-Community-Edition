# 莉莉白 / Lily White

- 原画作者：**dairi**；角色：东方 Project 的莉莉白。
- 输入素材：用户提供的 `48553357_p0.png` 至 `48553357_p21.png`（650 × 990 RGBA）。
- 用户已确认该素材可非商业使用、修改；此处仅作非商业项目适配，不授予超出原作者许可的权利。分发时请保留作者署名并遵循原素材条款。
- 对话与结算鼓励语为本项目新增文本，不是官方台词。

## 加工方式

使用 `Tools/Art/prepare_lily_white.py <源素材目录>` 重建四张 PNG，需要 Pillow；源文件不会被改写。

| 文件 | 内容 |
| --- | --- |
| `lily-white-stand.png` | p0 原始立绘，无裁切与重绘 |
| `emos.png` | p1–p21 的 160 × 160 脸部差分，5 × 5 网格，左上角定位在原图 (80, 200) |
| `blink.png` | p5 的闭眼补片，保持原图尺寸与坐标；仅适用于配置列出的表情 |
| `motion.png` | RGB 权重图：红=翅膀、绿=发梢、蓝=裙摆；不是显示图层 |

这是保留原画的轻量分区网格动画，不是 Live2D Cubism 模型，也不依赖 Cubism SDK。贴图、眨眼许可表情、运动强度与各评级反应均通过 `chara.json` 配置。旧版静态人物仍沿用原表情协议。
